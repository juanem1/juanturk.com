# Add site-wide footer with copyright line and current year

**Task:** task-1793628100267

**Branch:** `feat/task-1793628100267-add-site-wide-footer-with-copyright-line`

## Request

Add a simple footer in all pages with the classic two lines and date.
The date should be a function showing the current year

## Summary

Show a simple footer on every page. It has the "classic two lines" and a date computed by a function that returns the current year.

## Acceptance criteria

- A footer appears on all pages (site and blog layouts).
- The footer has two lines of text.
- The footer shows a date whose year comes from a function returning the current year.

## Plan

In `src/layouts/BaseLayout.astro`, replace the commented `currentYear` line with `const getCurrentYear = () => new Date().getFullYear();`. Uncomment the footer after `</main>` and give it two `<p>` lines: `&copy; {getCurrentYear()} Juan Turk` and `All rights reserved.` Keep the existing footer classes. I chose the year-only form and the copyright plus "All rights reserved" wording because they are the simplest reading of "classic two lines and date." A breakdown isn't needed because this is one change in one file. Every page uses `BaseLayout`, so the footer appears everywhere, and `SiteLayout` already has a `:global(footer)` rule that keeps it above the backdrop. One caveat: the site is static, so the year is set when the site is built, not when someone visits.
