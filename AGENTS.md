# Repository Instructions

Editorial guidance for new posts lives in the project skill at `.agents/skills/write-new-blogpost/SKILL.md` and its `references/house-style.md` reference. Those files are the single source of truth for blog-post authoring rules.

Visual design guidance (colors, typography, layout, components, motion) lives in `DESIGN.md` at the repository root, following the [DESIGN.md format](https://github.com/google-labs-code/design.md). Read it before creating or changing UI, and update it when the design system changes.
